# Árvore Binária de Busca (ABB)

Projeto acadêmico desenvolvido em linguagem C para a disciplina de Estrutura de Dados.

## Funcionalidades
- Leitura de registros do arquivo `dados.txt`
- Inserção de elementos em uma árvore binária de busca
- Exibição da estrutura da árvore no terminal
- Liberação da memória utilizada

## Tecnologias
- Linguagem C

## Como executar
Com um compilador GCC instalado, execute na pasta do projeto:

```bash
gcc main.c arvore.c arquivo.c -o programa
./programa
```

No Windows, o executável gerado pode ser iniciado com `programa.exe`. Mantenha o arquivo `dados.txt` na mesma pasta ao executar.
